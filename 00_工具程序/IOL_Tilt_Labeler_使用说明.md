# IOL Tilt Labeler 使用说明

## 你要做什么

把 OCT 原图放进同一个文件夹，逐张人工点位。软件自动计算：

```text
最终夹角 = IOL 轴 Angle − A-B 瞳孔平面 Angle（取锐角）
```

结果保留三位小数，自动写入 Excel。

## 启动

- macOS：双击 `IOL 倾斜标注.app`（独立打包，不依赖系统 Python），或双击 `启动IOL标注工具.command`
- Windows：开始菜单里的 **IOL Tilt Labeler**
- 源码运行：`python -m venv .venv && .venv/bin/pip install -r requirements.txt`，然后
  `.venv/bin/python 00_工具程序/iol_tilt_labeler_qt.py`

## 每张图的点位顺序

1. `1 C-D 参考线`：沿虹膜走行点几个参考点，帮助判断 A/B 根部。**不参与计算**，只做视觉参考。
2. `2 A-B 瞳孔平面`：点 2 个虹膜根部 A、B。这个角度就是瞳孔平面 Angle。点满 2 个自动跳到第 3 步。
3. `3 晶体前表面`：推荐 4 个点，必须落在前表面弧线上。
4. `4 晶体后表面`：推荐 4–8 个点，必须落在后表面弧线上。
5. `5 自动轴校验`（可选）：点 2 个参考点，只用来和自动轴对照，左栏「校验差」会显示两者差值。
   只有在前/后表面点不够、生成不出自动轴时，它才会被当作兜底参考轴。
6. 点「保存并下一张」。最后一张保存后会提示全部完成。

**自动轴优先**：只要前后表面各有 3 个以上点，IOL 轴一律由圆拟合的交点决定。

## 改点位

| 操作 | 效果 |
| --- | --- |
| 拖动已有的点 | 微调位置 |
| `⌥` / `Alt` + 点击某点 | 删除这个点 |
| 选中点后按方向键 | 微调 1 px（`⇧` / `Shift` 一次 5 px）|
| `Delete` | 删除选中的点 |
| `⌘Z` / `Ctrl+Z` | 撤销（每张图独立一条撤销链）|
| `⇧⌘Z` / `Ctrl+Shift+Z` | 重做 |

## 看清楚一点

- **放大镜**：默认开启，光标附近浮出 4 倍圆形放大窗，点位标记同步显示。`⌘L` 开关。
- **准星**：`⌘K` 开十字线，方便对齐。
- **图像调节**：左栏可拉亮度 / 对比度，或「反相显示」。只影响显示，**不影响测量结果**。
- 滚轮缩放，右键 / 中键拖动平移，双击空白适配窗口，`⌘0` 适配，`⌘1` 实际像素。

## 输出文件

选择的图片文件夹下面会自动生成：

```text
IOL_Tilt_Output/labels.json                 # 全部点位，可继续编辑
IOL_Tilt_Output/iol_tilt_results.csv        # CSV 表格
IOL_Tilt_Output/iol_tilt_results.xlsx       # Excel 表格
IOL_Tilt_Output/annotated/*_annotated.png   # 每张图的标注结果
```

Excel / CSV 只有四列：`IOL轴角度`、`A-B角度`、`最终夹角`、`备注`。

## 保存逻辑

- 点位改动即时写入 `labels.json`，关软件不丢。
- Excel / CSV / 标注图要点「保存」或「保存并下一张」才更新。
- 保存后又改点、撤销或清空，这张图会退回未完成，旧角度会从表格里清掉，需要重新保存。
- 多选不同文件夹里的同名图片时，软件自动用短 hash 区分，避免互相覆盖。

## 进度怎么看

左栏「图片列表」每行前面的小圆点：灰 = 未开始，橙 = 标注中未保存，绿 = 已保存。
底部状态条实时显示光标坐标、缩放倍数和「已完成 x/y」。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `1`–`5` | 切换标注步骤 |
| `S` / `⌘S` | 保存当前图 |
| `⌘⏎` | 保存并下一张 |
| `N` / `P` | 下一张 / 上一张 |
| `F` / `⌘0` | 适配窗口 |
| `⌘1` | 实际像素 |
| `L` / `⌘L` | 放大镜 |
| `⌘K` | 十字准星 |
| `⌘O` / `⇧⌘O` | 打开文件夹 / 打开图片 |
| `⌘E` / `⇧⌘E` | 打开 Excel / 打开输出文件夹 |

Windows 上把 `⌘` 换成 `Ctrl`、`⌥` 换成 `Alt`。
备注框里输入字母不会触发快捷键，放心写备注。

## 关键注意

A/B 必须按既定逻辑取：先看 C-D 虹膜走行，再据此判断 A/B 虹膜根部，不要直接拿 C/D 当瞳孔平面。

测量结果是**二维** IOL 相对 A-B 参考线的夹角，不是三维临床 IOL tilt、环曲 IOL 旋转或偏心量。
